# Entropic c-theorem in Lean 4

A Lean 4 formalization of Theorem 1 of

> J. Kudler-Flam, *Proof of the entropic c-theorem* (2026),

a cutoff-free version of the Casini–Huerta entropic c-theorem in 1+1 dimensions, stated with Araki's
relative entropy in algebraic quantum field theory.

> **Caveat.** This code was written by AI models (Claude and ChatGPT). Lean checks every proof, and the
> main theorem depends only on Lean's three standard axioms. However, no human has checked that the
> definitions and the formal statement faithfully represent the theorem of the paper, so the code should be
> taken with a large grain of salt.

## The main theorem

`CTheorem.CNet.cTheorem` in [`ModularCTheorem/CTheorem.lean`](ModularCTheorem/CTheorem.lean):

```lean
theorem cTheorem [TopologicalSpace.SeparableSpace H] {cUVR cUVL : ℝ}
    (huvR : ∀ a A b : ℝ, 0 < a → a ≤ A → 0 < b →
      N.DRe a A b ≤ ((cUVR / 6 * Real.log (A / a) : ℝ) : EReal))
    (huvL : ∀ a b B : ℝ, 0 < a → 0 < b → b ≤ B →
      N.DLe a b B ≤ ((cUVL / 6 * Real.log (B / b) : ℝ) : EReal)) :
    ∃ fR fL : ℝ → ℝ,
      (∀ r, 0 < r → 0 ≤ fR r) ∧ (∀ r, 0 < r → fR r ≤ cUVR) ∧ AntitoneOn fR (Ioi 0) ∧
      (∀ r, 0 < r → 0 ≤ fL r) ∧ (∀ r, 0 < r → fL r ≤ cUVL) ∧ AntitoneOn fL (Ioi 0) ∧
      (∀ a b, 0 < a → 0 < b →
        HasDerivWithinAt (fun A => N.DR a A b) (fR (Real.sqrt (a * b)) / (6 * a)) (Ici a) a) ∧
      (∀ a b, 0 < a → 0 < b →
        HasDerivWithinAt (fun B => N.DL a b B) (fL (Real.sqrt (a * b)) / (6 * b)) (Ici b) b) ∧
      (∀ a b, 0 < a → 0 < b → N.CR a b = fR (Real.sqrt (a * b))) ∧
      (∀ a b, 0 < a → 0 < b → N.CL a b = fL (Real.sqrt (a * b)))
```

In words: the right derivatives defining `C_R` and `C_L` exist, `C_R(a,b)` and `C_L(a,b)` depend only on
`r = √(ab)`, and both are non-negative, bounded by the ultraviolet constants, and non-increasing in `r`.

axiom anywhere in the dependency chain.

### Hypotheses

`N : CNet H` ([`ModularCTheorem/Net.lean`](ModularCTheorem/Net.lean)) is a net `A : Diamond → VonNeumannAlgebra H`
with a vacuum vector `Ω`, with exactly the hypotheses the proof uses.

| field of `CNet` | in the paper |
|---|---|
| `isotony`, `locality` | Haag–Kastler axioms |
| `covariance` | covariance under boosts about `p`, with a boost-invariant vacuum |
| `generation` | the algebra of a causal diamond is generated by those of the diamonds whose closures it contains |
| `split`, `finiteMI` | first assumption, eq. (3.3) |

In addition, the theorem assumes `[SeparableSpace H]` and the ultraviolet bounds `huvR`, `huvL` (the second
assumption). Positive energy, translations, and the uniqueness and cyclicity of the vacuum are not assumed.

## How Proposition 2 is proved here

The paper derives Proposition 2 from Lemma 3, which uses the chain rule (3.6) for type III algebras and the
bound `I ≤ 2 log d`. The formalization uses neither. Instead:

1. [`TypeI/Approximation.lean`](ModularCTheorem/TypeI/Approximation.lean). A type I factor on a separable Hilbert
   space is generated by an increasing sequence of unital matrix subfactors (`T4.exists_mu_approx`;
   the type I∞ case uses `2ⁿ × 2ⁿ` matrix units built from a Cuntz pair). For type I factors `X' ⊆ X` there are
   compatible sequences `P n ↑ X'` and `R n ⊆ X'′` with `P n ∨ R n ↑ X` (`exists_matrixSubfactor_seq_pair`).
2. [`Araki/MatrixFactor.lean`](ModularCTheorem/Araki/MatrixFactor.lean). On matrix subfactors, Araki's relative
   entropy is Umegaki's (`arakiEntropy_eq_umegakiEntropy`), and QuantumSystem's finite-dimensional strong
   subadditivity gives the four-term inequality `mutualInfo_fourTerm`.
3. [`TypeI/SSA.lean`](ModularCTheorem/TypeI/SSA.lean). Upward continuity passes it to type I factors:
   for type I factors `X' ⊆ X`, `Z' ⊆ Z` with `X ⊆ Z′` and `I(X:Z) < ∞`,
   `I(X':Z) + I(X:Z') ≤ I(X:Z) + I(X':Z')` (`mutualInfo_add_le_of_isTypeIFactor`).
4. [`CTheorem.lean`](ModularCTheorem/CTheorem.lean). The split property gives increasing type I factors
   exhausting `𝒜(L_A) ⊆ 𝒜(L_a)` and `𝒜(Y_1) ⊆ 𝒜(Y_2)` (`Net.lean`). Step 3 at each level and upward
   continuity in the limit give eq. (3.4) (`fourTerm_of_ladders`, `CNet.ymono`).

## Not formalized

Only Theorem 1, with Proposition 2 along the way. The interpretations at the end of Sec. 3.3 (minimal null energy,
recovery) and the discussion of fixed points in Sec. 4 are not formalized.

## Building

With [elan](https://github.com/leanprover/elan) installed:

```
lake exe cache get
lake build
```

Versions are pinned: Lean v4.35.0, Mathlib v4.35.0, and
[kencyke/quantum-system](https://github.com/kencyke/quantum-system) (Apache-2.0) at commit `7ae25d9`. That library
supplies von Neumann algebras, Araki's relative entropy and its monotonicity, type I factors and split
inclusions, and finite-dimensional strong subadditivity. To check the axioms yourself:

```lean
import ModularCTheorem
#print axioms CTheorem.CNet.cTheorem
```
